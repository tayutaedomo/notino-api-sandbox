## 日次作成

### 作成順序と失敗時の動作

- `all:create` はRetro → Body → Sleepの順に各1ページを作成します。
- Diaryは含みません。
- 途中の失敗で後続を停止し、終了コードは非0になります。
- 全体のトランザクションや再実行時の重複排除はありません。

### タイトルと日付

| 対象 | DBの環境変数 | Name | Date |
|---|---|---|---|
| Retro | `NOTION_DB_ID_1` | `YYMMDD Retro` | `YYYY-MM-DD` |
| Body | `NOTION_DB_ID_2` | `YYMMDD Body` | `YYYY-MM-DD` |
| Sleep | `NOTION_DB_ID_3` | `YYMMDD Sleep` | `YYYY-MM-DD` |

日付は東京時間で決定します。

## 照会と取得

| コマンド | 保証する動作 |
|---|---|
| 各 `*:query` | Created time降順で最大3件取得し、結果と先頭ページを表示 |
| `auth` | ユーザー一覧による認証確認 |
| `diary:page` | 指定ページの取得 |
| `diary:blocks` | 直下ブロックの最初のページを取得 |
| `search` | 空文字列による検索結果の最初のページを表示 |

## 複製

### 当日のDiaryを作る

`diary:dup` は次の条件でコピー元を選び、本文を複製します。

- 選択：Tagsに `diary` を含むページをName降順で取得。
- 新しいName：`YYMMDD Diary`。
- Month：`YYYYMM`。
- Tags：`diary`。
- アイコン：😃。

### 条件に一致するページをコピーする

- `retro:dup` / `diary:dup2` はNameを文字列検索し、Created time降順で選択します。
- 汎用CLIの検索対象は `title` または `rich_text` です。
- プロパティ、本文、絵文字／外部アイコン、外部カバーをコピーします。
- `formula`・`rollup`・作成／更新情報などの読み取り専用プロパティは除外します。
- `copiedBlocks` はコピーした直下ブロックの合計件数です。

### 本文の共通処理

- 全階層をページネーションで取得し、最大100件ずつ追加します。
- TODOは未チェック化し、ブロックの順序と子階層を維持します。
- 空本文は追加リクエストなしで成功します。
- コピー元がなければ明確なエラーになります。

## HTTP

### 公開する機能

| 関数 | 引数 |
|---|---|
| `helloWorld` | なし |
| `notionAuth` | なし |
| `notionCreatePage` | `id`、任意 `title` |
| `notionDuplicatePage` | `id` |
| `notionCopyPage` | `db`、`sp`、`sv`、`so`、任意 `sod` |

- 既存の入力とアプリ独自の戻り値キーを維持します。
- 内包するNotionの生JSONは新API仕様に従います。

### コピーのHTTPエラー

- 必須パラメータなし：400。
- コピー元なし：404。
- コピー処理の例外：500。

## 移行による改善

| 対象 | SDK 2.2.15での制約 | 移行後 |
|---|---|---|
| Diary本文 | 直下100件まで | 全階層・全ページを取得 |
| 汎用コピーの追加 | 100件単位に分割しない | 最大100件ずつ追加 |
| `status` | コピーしない | コピーする |

## コピーの制約

### 作成できないブロック

対象外のブロックは読み飛ばさず、新ページ作成前にエラーにします。

- `template`（旧テンプレートボタン）。
- `meeting_notes` / `transcription`。
- `child_page` / `child_database` / `link_preview` / `unsupported` など。
- 新しい `heading_4` / `tab` の作成対応も今回追加しません。

### 同期ブロックとレイアウト

- 同期ブロックは独立した本文としてコピーし、元への同期は維持しません。
- テーブルは最初の行、カラムは初期の子ブロックを含めて作成し、残りを順に追加します。
- `width_ratio` があれば送信します。幅やレイアウトの正確な再現は保証対象外です。
- 空のカラム、2列未満のカラム一覧、カラム先頭にテーブル／カラム一覧がある構造は事前に拒否します。

### メディア

- 内部メディアは元URLを `external` として作成します。
- ファイルの再アップロードは行いません。
- 署名付きURLの寿命は延長しません。
- 新しいブロック種別の作成対応は今回の範囲外です。
